## 📖 About
I started this project with the aim of getting started on ML. so far I managed to train a neural network with 2 hidden layers using MNIST from tensorflow that predicts human-written number from a sample picture of 28x28 pxls. I integrated that AI with flask and did some frontend development with HTML, CSS and JS and now you can access this experience from web.

🎥 [Watch the video]()

## Features
- **Interactive Drawing-Canvas**: Allows you to draw digits directly on the webpage.
- **Handwritten Digit-Recognition**: Uses a trained AI model to recognize what's written in the canvas.
- **Canvas Reset:** Allows you to reset the canvas and try a new digit.
- **Web-Based Interface:** Provides an accessible interface built with HTML, CSS and JS, powerd by Flask backend.
- **Probability Graph:** A graph that shows how much your digit represents the prediction by AI.

## 🚀 How to run:
1. Mouse-drag to draw on the Canvas.
2. Clear button for resetting the Canvas.
3. Recognize button for predicting what's the drawn number.
